# Conclave for iPhone

The native iPhone and iPad app for [Conclave](https://github.com/liehrdot/Conclave), written in Swift and SwiftUI.
It talks to the same sync server (or Conclave Cloud) as Conclave's phone web app.

It is built in GitHub Actions; [docs/sideload.md](docs/sideload.md) says how to put it on an iPhone
with a free Apple ID.
